The old READMEs, classified against reality

This is the inventory for the task #inventory-the-old-readmes-against-reality. It walks every claim in README.md and doc/README.zh-cn.md at v1.2.2 (d1e1ee9) and classifies each as still-true (the rewrite carries the substance, reworded), stale (the rewrite must replace it), or fork-unique (fork-era material that is accurate and stays, integrated rather than rewritten away). The stale digest at the end is the replacement worklist the later tasks consume.

Reality it classifies against: the software is udpspeeder-simd v1.2.2, a fork of wangyu-'s UDPspeeder with SIMD FEC kernels and per-CPU dispatch, a DNS lease manager, socket marks (--fwmark, --cookie, --dscp) with an honor-or-refuse contract, four-host CI that reads the priority byte off the wire, an OpenWrt feed package, and ten release assets covering seven Linux arches, both Windows worlds, and one universal macOS binary.

The EN-zh divergence

The Chinese file carries strictly more upstream residue than the English one: the personal anecdote, the v1/v2 version talk, the keyword block, the VM image instructions with password, and the old architecture names all survive only on the Chinese side. That is the concrete content of "one version behind": the fork-era updates (binary rename, marks sections) landed on both, but nothing ever pruned the Chinese side's older strata. The 1:1 rewrite closes this by construction: one structure, two languages, same mermaid blocks.

The stale digest: what the rewrite must replace

  1. Identity. The name and title story on both files, replaced by the fork's own front door with the credit link up front.
  2. Platform and install truth. Upstream release URL, the VM image (and its root password), old arch names, Android and RPi claims. Replaced by the ten-asset four-host table, the privileges table, and the feed.
  3. Efficacy presentation. Upstream's 2018 screenshots and unanchored numbers. Replaced by claims traced to OPTIMIZATION.md, the bench lane, or stated FEC arithmetic.
  4. The VPN stacking story. Upstream's confirmed-VPN list and wiki guide pointer. Replaced by the fork's VPN-over-tunnel family with the MTU ledger.
  5. The options banner. The v1.0.6 block regenerated from the real v1.2.2 help output.
  6. Upstream's voice. The personal anecdote, v1/v2 version talk, keyword block, competitor comparison.
  7. Every upstream image reference. Three mermaid blocks replace them.
  8. The wiki as primary pointer. The fork's doc/ owns applied material; the upstream wiki remains as credited further reading.

What carries: the FEC/Reed-Solomon substance, the quick-start shape, all option semantics and the per-option explanations, the fifo section, both marks sections, the related-repo pointers, and the language pairing. What is already ours: the marks options and sections, the renamed binary in examples, the repository credit lines in the help block, and doc/socket-marks.md.
